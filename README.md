🏋️ Membresías NFT para Gimnasio (dApp)

Frontend de una dApp que permite comprar y gestionar membresías NFT utilizando MetaMask y un smart contract en Ethereum.
El proyecto tokeniza membresías de gimnasio como NFTs ERC-721, permitiendo que los usuarios adquieran una membresía digital verificable en la blockchain.
Además, el sistema entrega automáticamente un POAP (Proof of Attendance Protocol) cuando un usuario realiza su primera compra.

📌 Descripción del proyecto

Este proyecto fue desarrollado como trabajo práctico de Blockchain.
La idea es reemplazar el modelo tradicional de membresías de un gimnasio por un sistema descentralizado, transparente y verificable, donde:
-La membresía es un NFT único
-La propiedad se verifica en blockchain
-Las reglas se ejecutan automáticamente mediante smart contracts
El sistema combina:
-Smart Contract en Solidity
-Frontend Web (HTML, CSS, JavaScript)
-MetaMask
-IPFS para metadatos
-Red de pruebas Sepolia
